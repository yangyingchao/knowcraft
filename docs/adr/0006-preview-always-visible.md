# ADR 0006：主窗口预览常驻与宽度持久化

- 日期：2026-11-07
- 状态：已采纳
- 关联设计：`docs/superpowers/specs/2026-11-07-preview-always-visible-design.md`

## 背景

预览面板原先由 `Space` 开关，`Esc` 也会关闭。面板宽度只保存在内存，重启后按可用宽度重新计算。
用户要求主窗口的预览面板始终可见，并在下次启动恢复上一次宽度；文件选择与保存对话框仍需要
可关闭的预览。

## 决策

1. `PreviewDrawer` 增加构造期 `resident` 参数。主窗口为 `true`，对话框为 `false`。
2. 主窗口 `enabled` 初始为 `true`，用户操作不再改变可见性；只有布局空间不足与控件销毁能收起
   或停止面板。对话框初始关闭，保留原有开关行为。
3. `Space` 改为打开并聚焦预览：确保可见、显示目标、把键盘交给预览，不再关闭。
4. `Esc` 与 `Shift+Esc` 在预览内只把焦点交回文件列表，保留当前内容。查找栏、密码框等临时层
   先处理各自的 Esc。
5. 预览 header 的关闭按钮在主窗口隐藏；对话框保留。
6. 面板宽度保存到 `$XDG_STATE_HOME/knowcraft/preview.toml`（回退 `~/.local/state/`），
   不写入 `settings.toml`。只有主窗口读写该文件。
7. 保存的宽度是分隔线右侧槽位的宽度，包含 grip 与可选的标签栏，不包含内容区口径转换。
8. 保存触发条件为：确实结束一次拖动、存在手动宽度、未处于窄窗口挂起、值与上次落盘值不同。
   窗口销毁前补一次同样的保存判定。

## 后果

- 主窗口不再存在“预览被用户关闭”的状态；选择跟随与占位始终有效。
- `Space` 的语义从开关变为打开并聚焦，快捷键参考与相关测试需要同步。
- `Esc` 的优先级扩展为：预览临时层 → 预览回焦 → 直接搜索 → 选择清理。
- 对话框与主窗口共用组件，通过一个布尔区分驻留策略；分支点限制在初始化、关闭、关闭按钮与
  宽度读写，不新增控制器层。
- 宽度文件损坏或版本不符时按无记录处理，首次有效拖动会覆盖；该文件是临时 UI 状态，
  不提供设置项或迁移。
- 删除失去调用方的 `leave_or_close_preview`、`close_preview`、`toggle_file_preview`，
  避免留下重新接通关闭语义的入口。
